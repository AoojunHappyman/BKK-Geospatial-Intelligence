# ฐานข้อมูลเริ่มต้น BKK Geospatial Intelligence

นำเข้าข้อมูลจริงครบ 50 เขต วันที่ 1 ตุลาคม 2569

## ไฟล์หลัก

| ไฟล์ | เนื้อหา |
|---|---|
| processed/district_population_2025.csv | ตารางพร้อมวิเคราะห์ 50 เขต ประชากร เพศ อายุ พื้นที่ และความหนาแน่น |
| processed/districts.geojson | ขอบเขต 50 เขต พิกัด WGS84 พร้อมข้อมูลประชากรใน properties |
| processed/district_population_age_2025.csv | อายุรายปี 0–100 และ 101+ แยกชาย/หญิง จำนวน 5,100 แถว |
| processed/district_population_age_exclusions_2025.csv | สี่กลุ่มที่ต้นทางแยกออกจากชุดแจกแจงอายุ จำนวน 200 แถว |
| processed/districts.csv | ทะเบียนเขต รหัส ชื่อไทย/อังกฤษ พื้นที่ และวันที่ทรัพยากรขอบเขต |
| processed/district_name_crosswalk.csv | การจับคู่ชื่อในไฟล์อายุกับรหัสเขตจากไฟล์ประชากร |
| processed/bkk_base.sqlite | ฐานข้อมูล SQLite พร้อม primary key และ foreign key |
| processed/validation_report.json | ผลตรวจข้อมูล geometry การแก้ชื่อ และข้อจำกัด |
| raw/manifest.json | URL วันที่ดาวน์โหลด ขนาด และ SHA-256 ของไฟล์ต้นฉบับ |

CSV ใช้ UTF-8 พร้อม BOM เพื่อเปิดภาษาไทยได้สะดวก รหัสเขตเป็นตัวระบุแบบข้อความ 4 หลัก หนึ่งแถวในตารางหลักหมายถึงหนึ่งเขต ณ ช่วงเวลาเดียวกัน

## ช่วงเวลาและแหล่งข้อมูล

- ประชากรและอายุ: เดือนธันวาคม 2568 (`2025-12`, รหัสต้นทาง `6812`) จากกรมการปกครอง ใช้ปีเต็มเดียวกันเพื่อเปรียบเทียบได้ ไม่อ้างว่าเป็นข้อมูลรายเดือนล่าสุดของปี 2569
- [ประชากรรายเขต](https://stat.bora.dopa.go.th/new_stat/file/68/stat_a68.txt)
- [ประชากรรายจังหวัดสำหรับตรวจยอดรวม](https://stat.bora.dopa.go.th/new_stat/file/68/stat_c68.txt)
- [ประชากรแยกอายุกรุงเทพฯ](https://stat.bora.dopa.go.th/new_stat/file/6812/6812cc10.txt)
- [พจนานุกรมข้อมูลอายุ](https://stat.bora.dopa.go.th/new_stat/webPage/statByAge.php)
- [ขอบเขต 50 เขตของ กทม.](https://data.go.th/en/dataset/50): ทรัพยากร ZIP ระบุปรับปรุง 9 มีนาคม 2564 ไม่ได้ระบุวันที่ขอบเขตมีผลบังคับใช้ จึงเก็บแยกจากวันที่ประชากร

ไฟล์ต้นฉบับอยู่ใน raw และตรวจ checksum ก่อนนำเข้าทุกครั้ง เงื่อนไขอนุญาตของชุดขอบเขตในหน้ารายการระบุ License not specified ส่วนข้อมูลกรมการปกครองยังไม่ได้ยืนยันใบอนุญาตแจกจ่ายต่อ บันทึก URL เพื่อกลับไปตรวจเงื่อนไขก่อนเผยแพร่ชุดข้อมูลต่อสาธารณะ

## การตรวจสอบที่ผ่าน

- รหัส 1001–1050 ครบและไม่ซ้ำทั้งข้อมูลขอบเขต ประชากร และอายุ
- ประชากรรวม 5,422,568 คน: ชาย 2,526,272 คน หญิง 2,896,296 คน
- จำนวนบ้านตามทะเบียนรวม 3,356,358 หลัง ไม่ตีความเป็นจำนวนครัวเรือน
- ผลรวม 50 เขตตรงกับยอดกรุงเทพฯ ในไฟล์ระดับจังหวัด ทั้งชาย หญิง รวม และบ้าน
- ยอดจากไฟล์อายุตรงกับไฟล์ประชากรทุกเขต และทุกคอลัมน์อายุ/กลุ่มพิเศษรวมตรงกับแถวกรุงเทพฯ
- geometry ทั้ง 50 เขตผ่านการตรวจ validity โดยไม่ต้องซ่อม geometry
- แปลง EPSG:32647 เป็น EPSG:4326 โดยยึด CRS จากไฟล์ .prj
- แก้ชื่อในขอบเขตรหัส 1024 จาก “ราษฏร์บูรณะ” เป็น “ราษฎร์บูรณะ” ตามชื่อกรมการปกครอง และบันทึกไว้ในรายงาน
- SQLite ผ่าน integrity check และ foreign key check

## ความหมายของตัวแปรหลัก

| ตัวแปร | ความหมาย / หน่วย |
|---|---|
| district_code | รหัสเขต 4 หลัก |
| district_name_th / district_name_en | ชื่อเขตไทยตามกรมการปกครอง / อังกฤษจากขอบเขต |
| reference_period | ช่วงเวลาประชากร รูปแบบ YYYY-MM |
| boundary_resource_date | วันที่ปรับปรุงทรัพยากรขอบเขตจากหน้ารายการ ไม่ใช่วันที่กฎหมายมีผล |
| area_km2 | พื้นที่ polygon คำนวณใน EPSG:32647 หน่วย ตร.กม. |
| population_male / population_female / population_total | ประชากรทะเบียน ชาย/หญิง/รวม หน่วยคน |
| registered_houses | จำนวนบ้านตามทะเบียน หน่วยหลัง |
| age_classified_thai_population | ประชากรในชุดแจกแจงอายุของกรมการปกครอง หน่วยคน |
| population_age_0_14 | รวมอายุ 0–14 ปีในชุดแจกแจงอายุ หน่วยคน |
| population_age_15_59 | รวมอายุ 15–59 ปีในชุดแจกแจงอายุ หน่วยคน |
| population_age_60_plus | รวมอายุ 60 ปีขึ้นไป รวม 101+ ในชุดแจกแจงอายุ หน่วยคน |
| population_outside_age_series | ผลรวมสี่กลุ่มที่แยกต่างหากจากชุดแจกแจงอายุ หน่วยคน |
| age_60_plus_share_of_age_classified_thai | จำนวนอายุ 60+ หารด้วยประชากรที่แจกแจงอายุ ค่า 0–1 |
| population_density_per_km2 | ประชากรทะเบียนรวม / พื้นที่ polygon หน่วยคน/ตร.กม. |

ในไฟล์อายุ `age_lower=0` คืออายุต่ำกว่า 1 ปี และ `age_lower=101, age_upper` ว่าง คือมากกว่า 100 ปี ไม่มีการคาดเดาอายุสูงสุด

## ขอบเขตประชากรและข้อจำกัด

กรมการปกครองนิยามชุดประชากรรายอายุว่าเป็นผู้มีสัญชาติไทยและมีชื่อในทะเบียนบ้าน ชุดนี้รวม 5,280,172 คน อีก 142,396 คนถูกแยกในต้นทางเป็นกลุ่มเกิดปีจันทรคติ ทะเบียนบ้านกลาง ไม่มีสัญชาติไทย และอยู่ระหว่างการย้าย จึงเก็บในตารางแยกและไม่กระจายอายุให้เอง

จำนวนผู้มีอายุ 60+ ในชุดแจกแจงอายุคือ 1,305,293 คน สัดส่วนที่คำนวณในตารางใช้ตัวหาร 5,280,172 คน ไม่ใช้ยอดประชากรทะเบียนรวม ห้ามตีความว่าสัดส่วนนี้ครอบคลุมอายุของคนทุกคนที่อยู่ในกรุงเทพฯ

พื้นที่ polygon รวมประมาณ 1,583.2631 ตร.กม. เป็นผลคำนวณจากไฟล์ขอบเขตที่นำเข้า ไม่ใช่พื้นที่สถิติทางการ ความหนาแน่นในตารางจึงใช้พื้นที่ชุดนี้อย่างสอดคล้องกัน หากต้องการเทียบสถิติทางการต้องนำเข้าพื้นที่ทางการเป็นตัวแปรอีกชุด

ไม่ใช้คอลัมน์ประชากรและสถานที่ที่ติดมากับ Shapefile เพราะไม่ทราบปีข้อมูล ประชากรทั้งหมดในตารางผลลัพธ์มาจากชุดกรมการปกครองปี 2568

## นำเข้าใหม่

ใช้ Python 3.13 ในสภาพแวดล้อมที่มีไลบรารีตาม requirements-import.txt หรือ environment ที่รองรับเวอร์ชันเหล่านั้น

```powershell
python -m pip install --target .runtime -r requirements-import.txt
python scripts/download_base_data.py
python scripts/import_base_data.py
```

การดาวน์โหลดถูกตรึงไว้ที่เดือนธันวาคม 2568 หากต้องการปีใหม่ต้องแก้ URL และ reference period พร้อมตรวจโครงสร้างต้นทางก่อนนำเข้า ห้ามเปลี่ยนเพียงชื่อไฟล์

ตาราง SQLite: districts, district_population, population_age, population_age_exclusions, sources โดย geometry เก็บเป็น GeoJSON text ใน districts ฐานนี้เป็น SQLite ปกติ ไม่ได้เปิดส่วนขยาย SpatiaLite

ตัวอย่าง SQL:

```sql
SELECT district_code, district_name_th, population_total,
       population_density_per_km2
FROM district_population
WHERE reference_period = '2025-12'
ORDER BY population_density_per_km2 DESC;
```
